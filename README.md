One server that serves the OpenAI Chat Completions API and the Anthropic Messages API — each in JSON and in server-sent events — over ten simulated free-tier model providers, routing every request to the best free model that can serve it and failing over when a provider refuses.

## Run it

```sh
node main.ts
```
